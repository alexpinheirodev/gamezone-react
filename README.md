# GameZone | Landing Page em React - Parte 2

## Autor

Adriano Coutinho

## Origem

Projeto individual desenvolvido a partir da página original `index.html` do grupo e da página `usuario.html` produzida na Parte 1.

## Site publicado

A preencher após a publicação no Netlify.

## Como executar

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

Para testar a versão de produção localmente:

```bash
npm run preview
```
